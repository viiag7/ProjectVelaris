# Development Process

Velaris follows a lightweight agile process optimized for a critical distributed system.

## Documents

## Core principles

1. Deliver small vertical slices.
2. Prioritize technical risk early.
3. Keep requirements and architecture decisions versioned with code.
4. Use Spikes for meaningful uncertainty.
5. Build security, reliability and observability into the work rather than adding them at the end.
6. Do not start more work than the team can finish.
7. Review outcomes and measurements at the end of every sprint.
