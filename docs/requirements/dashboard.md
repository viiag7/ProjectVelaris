# Dashboard Requirements

## RF-DAS-001 — Tenant Dashboard

The Tenant dashboard must provide at least:

- Environment count;
- Domain count;
- active Credential count;
- submitted Messages;
- processed recipients;
- quota used and remaining;
- delivered Deliveries;
- deferred Deliveries;
- failed Deliveries;
- expired Deliveries.

## RF-DAS-002 — Environment Dashboard

Each Environment must provide its own operational summary and quota usage.

## RF-DAS-003 — Time Filtering

Operational statistics must support filtering by time period.
